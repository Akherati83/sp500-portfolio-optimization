S&P 500 Portfolio Analysis & Optimization

A Python-based portfolio analysis project using historical S&P 500 stock data to explore risk, return, correlation, covariance, and diversification.

Project Overview
This project analyzes five major S&P 500 companies:

* Apple (AAPL)
* Microsoft (MSFT)
* NVIDIA (NVDA)
* Amazon (AMZN)
* JPMorgan Chase (JPM)

The analysis currently includes:

* Historical price data
* Daily returns
* Annualized returns
* Volatility
* Correlation and covariance
* Equal-weighted portfolio construction
* Portfolio risk and return
* Risk–return visualization

Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* yfinance

Current Stage

The project currently focuses on basic portfolio analysis and diversification.

The next stages will extend the analysis toward portfolio optimization, including the Sharpe ratio, efficient frontier, and portfolio backtesting.

Objective

The goal is to build a practical framework for understanding how portfolio weights, diversification, and risk–return characteristics interact, while developing practical Python skills for financial analysis.
